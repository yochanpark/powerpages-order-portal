# 2. 주문 자동화 흐름

포털에서 주문이 들어오면 두 가지가 자동으로 일어난다.
둘 다 Dataverse **행 추가·수정·삭제 트리거**(웹훅)로 시작한다.

## 주문번호 채번

```
트리거: 행이 추가되거나 수정되거나 삭제될 때
  → OrderType        (Compose)     주문 유형 판별
  → NumberConfig     (Dataverse)   유형별 채번 설정 조회
  → 조건             (If)          분기 처리
```

채번 규칙을 흐름에 하드코딩하지 않고 **Dataverse 설정 테이블(`NumberConfig`)에서 읽는다.**
주문 유형이 늘어나도 흐름을 고치지 않고 행만 추가하면 된다.

## 발주번호 갱신 시 관리자 통보

```
트리거: 행이 추가되거나 수정되거나 삭제될 때
  → 메일 보내기(V2)              (Office 365 Outlook)
  → 거래처 ID 기준으로 행 가져오기  (Dataverse)
```

주문이 생성되어 발주번호가 채워지면 관리자에게 메일이 나간다.
거래처 정보는 주문 행에 든 ID로 조회해 본문에 채운다.

## 흐름을 솔루션 안팎으로 나눈 이유

솔루션에는 흐름 5개가 들어 있고, 위 두 개는 **별도로 내보내 관리**했다.
포털 구성요소와 함께 움직여야 하는 흐름은 솔루션에 넣고,
연결(Connection)을 환경마다 다시 붙여야 하는 흐름은 따로 두는 편이 배포가 단순하다.
