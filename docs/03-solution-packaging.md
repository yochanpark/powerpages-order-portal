# 3. 솔루션 배포

## managed 로 내보낸다

고객 환경에는 **managed 솔루션**으로 배포했다.
unmanaged 와 달리 구성요소가 잠기므로 고객 환경에서 임의 수정이 되지 않고,
솔루션을 삭제하면 그 안의 구성요소가 함께 정리된다.

## 버전

```
1.0.0.1  →  1.0.0.3  →  1.0.0.4
```

managed 솔루션은 **같은 버전으로 덮어쓸 수 없다.** 수정할 때마다 버전을 올려 다시 내보낸다.
중간 버전이 비어 있는 것은 내부 검증에서 걸러진 빌드가 있었기 때문이다.

## 솔루션 구성

```
solution.xml               솔루션 정의·구성요소 목록
customizations.xml         테이블·폼·뷰 등 스키마 (1.8MB)
Formulas/                  수식 열 정의
Workflows/                 클라우드 흐름 5개 (JSON)
powerpagecomponents/       포털 구성요소 267개 + 웹파일
maskingrules/              데이터 마스킹 규칙 6종
Assets/ · metadataforarchivals/
```

## 밟은 지점

**게시자 접두어는 환경마다 다르다.** 기본 게시자로 만든 테이블은
`{PREFIX}_` 접두어가 환경 생성 시 자동으로 정해져,
다른 환경으로 옮길 때 이름이 맞지 않으면 참조가 깨진다.
포털 구성요소가 테이블을 논리명으로 참조하므로 여기서 걸리기 쉽다.
