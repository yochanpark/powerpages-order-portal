# Power Pages 주문 접수 포털

Microsoft **Power Pages**로 만든 외부 사용자용 주문 접수 포털이다.
거래처가 포털에서 주문을 등록하면 Dataverse에 행이 쌓이고,
Power Automate 흐름이 주문번호 채번과 담당자 통보를 맡는다.

고객사 납품 건이라 산출물(managed solution, 이미지, 실데이터)은 올리지 않는다.
**무엇을 어떻게 만들었는지만 기록한 문서**다.

---

## 구성

| 영역 | 내용 |
|---|---|
| 포털 | Power Pages 사이트 — 구성요소 **267개**, 타입 20종 |
| 테마 | `theme.css`로 기본 테마 재정의 + Bootstrap. 로고·이미지 20여 종 |
| 로그인 | `Account/SignIn` CSS 재정의 — 외부 인증 버튼 숨김, 카드형 레이아웃 |
| 데이터 | Dataverse 주문 테이블 + 채번 설정 테이블, 수식 열 정의 |
| 자동화 | 솔루션 내장 흐름 **5개** + 별도 내보낸 흐름 **2개** |
| 배포 | managed 솔루션, 1.0.0.1 → 1.0.0.3 → 1.0.0.4 |

---

## 설계에서 신경 쓴 것

**채번 규칙을 흐름 밖으로 뺐다.** 주문 유형별 채번 설정을 Dataverse 테이블에 두고
흐름이 유형명으로 조회한다. 유형이 늘어도 흐름을 고치지 않는다.

**메일 트리거를 "생성"이 아니라 "주문번호 열 변경"에 걸었다.**
트리거 필터링 특성을 주문번호 열 하나로 지정해, 주문이 만들어지는 시점이 아니라
채번이 끝난 시점에 통보가 나간다.

## 이 문서의 근거

내보낸 솔루션 패키지와 흐름 정의(JSON), 로그인 페이지 CSS를 직접 열어
**확인된 것만** 적었다. 확인되지 않은 의도나 경위는 쓰지 않았다.
플랫폼 기본값이 섞여 있는 부분은 기본값이라고 밝혔다.

| 자리표시자 | 원래 값의 성격 |
|---|---|
| `{PREFIX}_` / `{PREFIX2}_` | Dataverse 게시자 접두어 2종 |
